1. Structure of a Java Program

Every Java program follows a fixed structure:

package packageName;

import java.util.Scanner;

public class Main {
    public static void main(String[] args){
        System.out.println("Hello Java");
    }
}

Flow: Package → Import → Class → Main Method → Statements

2. Package

Packages organize Java classes into folders.

package com.company.employee;

3. Import

Imports allow access to predefined Java classes.

import java.util.Scanner;

4. Class Declaration

public class Student{
}

A class is a blueprint for creating objects.

5 & 6. Main Method

public static void main(String[] args){
    System.out.println("Welcome");
}
  • public - accessible by JVM
  • static - no object required
  • void - returns nothing
  • main - entry point
  • String[] args - command-line arguments
