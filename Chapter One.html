📜 History & Definition

Java is a high-level, object-oriented, platform-independent programming language developed by James Gosling in 1995.

⭐ Features

  • Simple
  • Object-Oriented
  • Platform Independent
  • Secure
  • Robust
  • Multithreaded
  • Portable
  • High Performance (JIT)

🌍 WORA

Write Once, Run Anywhere

🖥️ JVM, JRE & JDK

ComponentPurpose
JVMExecutes bytecode
JREProvides runtime environment
JDKDevelopment kit (JRE + Tools)

Remember: JDK > JRE > JVM

📦 Bytecode

Intermediate .class code generated by javac.

🚀 JIT Compiler

Converts frequently used bytecode into native machine code for faster execution.

🗑️ Garbage Collection

Automatically removes unreachable objects from memory.
