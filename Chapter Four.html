What is a Data Type?

A data type tells Java what kind of value will be stored, how much memory to allocate and what operations are allowed.

int age = 22;

Real-life: Like different containers (milk bottle, bucket, petrol tank) have different capacities, Java variables have different data types.

💻 Coding Exercise

public class DataTypesDemo{
 public static void main(String[] args){
  byte age=22;
  short year=2026;
  int salary=50000;
  long population=8000000000L;
  float height=5.7f;
  double pi=3.1415926535;
  char grade='A';
  boolean isPlaced=true;

  System.out.println(age);
  System.out.println(year);
  System.out.println(salary);
  System.out.println(population);
  System.out.println(height);
  System.out.println(pi);
  System.out.println(grade);
  System.out.println(isPlaced);
 }
}

⭐ Best Practices

  • Use int for integers.
  • Use double for decimals.
  • Use boolean for true/false.
  • Use meaningful names.
